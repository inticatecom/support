# Inticate Live Chat — Live Customer Service Solutions

> [!IMPORTANT]
> This application is in it's earliest state of development. DO NOT use this in production.

A modern solution for supporting your customers need. Making use of websockets, provide your customers with real-time instant messaging support and an intuitive interface to provide a simple and quick approach to getting in contact with your support team.

- Instant real-time messaging.
- Modern, easy-to-use interface.
- Easy integration for React sites by making use of our component library.

## Development Overview

- `/client` - The React component for embedding the live chat directly into websites.
- `/server` - The back-end websocket server allowing the client to connect and receive/send messages.
- `/admin` - The administrator interface, allowing users to create organizations and create API-keys to be used in conjunction with the React component.
